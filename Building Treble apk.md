## Building with Linux
- first have a prerequisites

`sudo apt-get install xmlstarlet`

- Maybe should have or create folders

`/vendor/hardware/overlay/`

- After all so go to /vendor/hardware/overlay/build/ folder and type in Terminal

```bash
bash build.sh
```
or click in rigth button mouse and choose "Execute in (your Terminal app)".

- Script start and the apk files is builded in the /vendor/hardware/overlay/build/ folder.
